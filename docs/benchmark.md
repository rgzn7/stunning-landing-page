# Benchmark

评测时间：2026-06-11

本轮评测覆盖 3 个典型 landing page 场景，每个场景分别比较启用 skill 与不启用 skill 的输出。评测重点不是像素级一致，而是页面是否具备可发布落地页应有的动效、视觉、文案和工程完整性。

## 场景

- 精品手冲咖啡品牌「山雾咖啡」：温暖品牌系，强调云南高山豆、手工烘焙和感官氛围。
- AI 代码审查工具 CodeLens：暗夜科技系，强调开发者元素、辉光、玻璃拟态和滚动编排。
- 儿童编程教育 App「码丁星球」：活泼游戏系，强调弹性动画、3D 按压按钮、家长信任感和儿童趣味。

## 结果摘要

| Metric | With Skill | Without Skill | Delta |
| --- | --- | --- | --- |
| Pass Rate | 100% ± 0% | 92% ± 7% | +0.08 |
| Time | 325.5s ± 24.9s | 301.3s ± 8.0s | +24.2s |
| Tokens | 523305 ± 187683 | 207123 ± 16607 | +316182 |

## 观察

- 启用 skill 后，3 个场景全部通过核心断言，包括滚动驱动动画、动效降级、Hero 视觉冲击力、无本地破图路径和主题文案匹配。
- skill 的主要收益在于稳定产出“有剧本的页面”，而不是只做基础的卡片堆叠或淡入动画。
- 成本是上下文消耗更高，因为会读取视觉基调、动画模式、技术工具和质量清单等参考文档。

## 核心断言

- 输出单个有效 HTML 文件。
- 实现滚动驱动动画。
- 实现 `prefers-reduced-motion` 降级。
- Hero 具备足够视觉冲击力。
- 不引用不存在的本地图片路径。
- 风格与主题匹配。
- 文案为主题定制，不使用 Lorem ipsum。
- 不使用 emoji 作为图标或装饰图形。
