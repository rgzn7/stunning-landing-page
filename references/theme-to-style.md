# 主题 → 风格映射决策表

拿到主题后，先判断它属于哪个情绪象限，再套用对应的视觉与动画体系。这一步决定了页面的"人格"，比任何单个动画效果都重要。

## 第一步：情绪定位

问自己：**访客看完这个页面，应该带着什么情绪离开？**

| 目标情绪 | 典型主题 | 基调原型 |
|------|------|------|
| 敬畏（"太强了"） | 旗舰硬件、AI 大模型、航天、汽车 | 科技旗舰系（Apple/Linear） |
| 愉悦（"好可爱/好好玩"） | 教育、儿童、宠物、游戏、社区 | 活泼游戏系（Duolingo） |
| 灵感（"我也想做一个"） | 设计工具、创作平台、模板市场 | 创意工具系（Canva/Figma） |
| 信任（"很专业，可以托付"） | 金融、医疗、企业服务、API | 工程信赖系（Stripe） |
| 渴望（"想拥有/想体验"） | 咖啡、餐饮、香氛、旅行、服饰 | 温暖品牌系（消费生活方式） |
| 好奇（"这是什么，再看看"） | 个人作品集、工作室、艺术展览 | 先锋实验系（Awwwards） |
| 记忆感（"这个人/团队很有自己的系统"） | 设计工程师、创意技术人、独立工作室、实验作品集 | OS-HUD 实验作品集系 |

主题跨象限时（如"儿童金融教育"），选一个主导情绪，用另一个做调剂（活泼为主、信任做底色：糖果色但排版工整）。

## 第二步：套用视觉体系

### 科技旗舰系

- **配色**：近黑底（`#0a0a0c`，别用纯黑）+ 单一品牌色辉光（电蓝/紫/青柠）+ 灰阶文字层级（`#fff` / `rgba(255,255,255,.6)` / `.35`）
- **字体**：无衬线几何感——Space Grotesk、Inter Tight、中文思源黑体 Bold；字重对比拉大（标题 700 vs 正文 400）
- **排版**：大留白、居中舞台式构图、内容窄列（`max-width: 1100px`）
- **动画气质**：缓慢、精准、有重量感；`power2.inOut`/`power3.out`，0.8~1.4s
- **质感层**：辉光 + 噪点；可加细网格背景

### 活泼游戏系

- **配色**：高饱和糖果色 2~3 个主色（草绿 `#58cc02`、亮紫、柠黄、天蓝）+ 白底或浅色底；圆角拉满（卡片 24px+，按钮全圆角）
- **字体**：圆润粗壮——Nunito/Baloo 2、中文用粗圆体风格（思源黑体 Heavy 也可）
- **排版**：大色块分区、波浪 SVG 分隔线、元素允许出格与倾斜
- **动画气质**：快、弹、过冲；`back.out(1.7)`/`elastic`，0.4~0.7s
- **质感层**：实色厚边框、3D 厚底按钮、贴纸式投影（offset 实色阴影）

### 创意工具系

- **配色**：白/浅灰底 + 彩虹渐变点缀（紫→粉→橙）；UI 卡片用真实产品界面感
- **字体**：友好无衬线——Inter、DM Sans、中文思源黑体 Regular/Medium
- **排版**：漂浮卡片拼贴、不对称布局、大量真实"作品"展示
- **动画气质**：轻盈跟手；`power2.out` + lerp 鼠标跟随，0.5~0.8s
- **质感层**：柔和大投影（`0 24px 60px rgba(0,0,0,.12)`）、渐变网格背景

### 工程信赖系

- **配色**：白底或深蓝底 + 一个克制的品牌色（Stripe 紫/靛蓝）；图表用和谐多色
- **字体**：中性精密——Inter、IBM Plex Sans、等宽字体点缀（代码/数据）
- **排版**：严格网格、1px 细线分隔、留白均匀；倾斜彩色分区做节奏变化
- **动画气质**：少而准，只在关键处动；`power2.out`，0.5~0.8s
- **质感层**：点阵/细网格背景、精致代码窗口、细线 SVG 图表

### 温暖品牌系

- **配色**：从产品本身取色——咖啡（奶油 `#f5efe6` + 深咖 `#2b1d12` + 琥珀）、茶（米白+黛绿）、香氛（裸粉+酒红）；低饱和、高质感
- **字体**：衬线展示字体——Fraunces、Playfair Display、中文思源宋体；正文可配无衬线
- **排版**：杂志式编辑排版、大图、首字母/数字章节编号、不规则图文穿插
- **动画气质**：舒缓优雅；`power2.out`，0.8~1.2s，视差幅度小
- **质感层**：噪点纸张感、细分割线、图片圆角或拱形裁切

### 先锋实验系

- **配色**：极简两色（黑白 + 一个高亮色如荧光绿/橘红），或全灰阶
- **字体**：超大体量展示字——标题可到 12vw；试试紧字距（`letter-spacing: -0.04em`）
- **排版**：打破网格、文字可被图片穿插遮挡、巨大页码/索引编号
- **动画气质**：戏剧性强；自定义光标 + Lenis 是标配，转场夸张但精准
- **质感层**：噪点 + 大面积留白本身就是质感

### OS-HUD 实验作品集系

- **配色**：浅色舞台（雾蓝、米白、浅灰）或反差黑白底 + 1 个高能荧光色作状态标记；不要全页同一蓝/紫渐变
- **字体**：主身份用粗几何无衬线，系统信息用等宽字体；字号层级极端，HUD 文本小而清晰，主宣言大而果断
- **排版**：固定全屏 HUD（品牌、导航、时间/坐标/状态）+ 中央签名物 + 错位作品档案网格；作品区用不透明的中性/品牌档案表面盖住 3D 主视觉，页面像一个可操作的界面，而不是普通栏目页
- **动画气质**：轻微实时反馈胜过密集转场；坐标、主题、声音、导航状态可变化，主视觉慢速漂浮或随鼠标转动
- **质感层**：WebGL/Three.js 玻璃材质、贴纸/印章式矢量装饰、点阵 focus 边框、轻微噪点或柔光背景
- **慎用**：不适合信息密集的 SaaS 转化页，也不适合需要强信任背书的医疗/金融主题；它表达的是人格、审美系统和探索欲

## 第三步：写出定位句

填空并写下来（这句话会约束后面所有决策）：

> 这是一个【基调原型】风格的页面，主色是【色】配【色】，标题用【字体】。访客滚动或切换状态时会感受到【情绪】，全页的签名时刻是【签名动画】。

写不顺这句话，说明定调有矛盾，回到第一步重选。
