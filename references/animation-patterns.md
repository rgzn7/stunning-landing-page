# 顶级网站动画交互模式拆解

本文档是模式库，分两部分：**按网站拆解**（理解各家的整体设计哲学）和**按模式速查**（挑选具体效果时用）。选择时记住：签名动画选 1 个，支撑模式选 3~5 个，全页缓动统一。

## 目录

- 第一部分：按网站拆解（Apple / Duolingo / Canva / Stripe / Linear / Awwwards 系）
- 第二部分：模式速查表（开场类 / 滚动叙事类 / 微交互类 / 氛围质感类）
- 第三部分：组合搭配建议

## 第一部分：按网站拆解

### Apple — 滚动即电影

**哲学**：把滚动条变成视频播放进度条。访客不是在"浏览页面"，而是在"用拇指控制一部产品宣传片"。

| 标志性手法 | 实现要点 |
|------|------|
| 滚动序列帧（scroll-scrubbed sequence） | sticky 容器 + canvas 逐帧绘制图片序列，ScrollTrigger `scrub: true`。无图片序列时可用 CSS 3D 变换替代（旋转/缩放一个产品造型的 div/SVG） |
| Sticky 定格叙事 | 一屏 `position: sticky` 固定住，滚动时屏内元素依次变化（文字换行、产品变色、参数浮现），滚完才放行进入下一屏 |
| 巨字渐显定场 | 超大标题（8vw+）从模糊/透明中浮现，常配合 `filter: blur()` 到清晰的过渡 |
| 深色聚光 | 纯黑背景 + 单一产品居中 + 径向渐变光晕，营造发布会舞台感 |
| 参数逐项浮现 | 技术参数随滚动一条条 fade + 上移进场，每条 stagger 0.1s |

**适用**：科技产品、硬件、高端旗舰感。**慎用**：内容轻松活泼的主题会显得装腔。

### Duolingo — 快乐的物理学

**哲学**：每个元素都像有生命、有重量、有弹性。快乐感来自"过冲"——动画不是到位即停，而是冲过头再弹回来。

| 标志性手法 | 实现要点 |
|------|------|
| 弹性过冲缓动 | GSAP `back.out(1.7)` 或 `elastic.out(1, 0.5)`；CSS 用 `cubic-bezier(0.34, 1.56, 0.64, 1)`（值 >1 产生过冲） |
| 3D 按压按钮 | 按钮底部有 4~6px 深色 `border-bottom`（同色系加深），`:active` 时 `translateY(4px)` + border 归零，像按下实体琴键 |
| 角色/吉祥物动画 | 用 SVG 插画或图标库大图标做主角，idle 时持续轻微浮动（`translateY` ±8px 循环），交互时眨眼/跳动 |
| 庆祝时刻 | 关键交互（点击 CTA、滚到里程碑）触发 confetti 粒子或星星迸发 |
| 糖果色块拼图 | 高饱和大色块分区（绿/紫/黄/蓝），区与区之间用波浪 SVG 分隔线过渡 |
| 进度游戏化 | 滚动进度条做成游戏血条/经验条样式，数字跳动累加 |

**适用**：教育、儿童、社区、宠物、游戏化产品。**慎用**：金融、医疗等需要严肃信任感的主题。

### Canva — 创意的漂浮感

**哲学**：让访客觉得"创作很轻盈"。界面元素像失重一样漂浮，处处暗示"拖一下试试"。

| 标志性手法 | 实现要点 |
|------|------|
| 浮动 UI 卡片拼贴 | Hero 区散布多张倾斜的卡片/模板缩略图，各自不同速度轻微浮动，z-index 层叠出景深 |
| 鼠标视差 | 监听 `mousemove`，各层按深度系数反向位移（近层动得多、远层动得少），用 `lerp` 平滑跟随 |
| 渐变网格背景 | 多个大色斑 `radial-gradient` 叠加 + `filter: blur(80px)`，缓慢位移营造极光感 |
| 模板瀑布流斜向滚动 | 多列图片以不同速度自动滚动（CSS `@keyframes` 平移 + 列间反向），整体可倾斜 5~10 度 |
| 即时上手暗示 | 页面内嵌一个可真实交互的迷你 demo（可拖动的元素、可点击换色的预览） |

**适用**：设计工具、创意平台、模板类、UGC 产品。

### Stripe — 工程美学

**哲学**：用克制和精密传达"我们的代码和我们的网页一样可靠"。动画少而准，质感全在细节。

| 标志性手法 | 实现要点 |
|------|------|
| 流动渐变 Hero | 经典的 WebGL 动态渐变；轻量替代：多个 blur 色斑用 CSS 动画缓慢旋转位移（详见 tech-toolkit.md 的 aurora 片段） |
| 精致代码窗口 | 带 macOS 红绿灯的代码卡片，代码逐行打字机出现或高亮行随滚动切换 |
| 细线条与网格 | 1px 边框、点阵/网格背景（`background-image: radial-gradient(circle, ...)` 1px 点），克制的几何感 |
| 数据可视化进场 | 图表线条用 SVG `stroke-dashoffset` 从 0 画出，柱状图从底部生长 |
| 倾斜分区 | section 之间用 `transform: skewY(-6deg)` 的彩色背景斜切过渡 |

**适用**：开发者工具、SaaS、金融科技、API 产品。

### Linear — 暗夜辉光

**哲学**：暗色宇宙中，光就是层级。重要的东西会发光。

| 标志性手法 | 实现要点 |
|------|------|
| 暗底辉光 | 近黑背景（`#08090a` 而非纯黑）+ 关键元素 `box-shadow: 0 0 80px` 品牌色辉光 |
| 玻璃拟态卡片 | `backdrop-filter: blur(12px)` + 半透明白边框（`rgba(255,255,255,0.08)`）+ 内侧高光（顶部 1px 渐变亮线） |
| 渐变描边 | 卡片边框用渐变（border-image 或双层嵌套），hover 时描边旋转流动 |
| 星空/粒子背景 | 少量缓慢漂移的微粒（canvas 或多个 box-shadow 的伪元素） |
| 文字渐变高亮 | 标题关键词 `background-clip: text` 渐变色，或扫光动画掠过 |
| 产品截图舞台化 | 截图带透视倾斜进场，hover 回正，配反射倒影 |

**适用**：开发者工具、AI 产品、效率工具、任何想要"未来感"的主题。

### Awwwards 获奖站常见手法 — 先锋实验系

这些手法冲击力最强，但实现成本和翻车风险也最高，作为签名动画单点使用：

| 手法 | 实现要点 |
|------|------|
| 自定义光标 | 隐藏原生光标，圆点 + 延迟跟随的圆环；hover 可交互元素时圆环放大并显示文字（"View"/"Drag"） |
| 巨字逐字浮现 | SplitType 拆字 + GSAP stagger，每字从 `y:100%` + `rotate` 翻上来，配 `overflow: hidden` 的行容器 |
| 文字乱码解码 | 标题字符快速随机翻转后逐个锁定为真实字符（text scramble） |
| 图片 hover 扭曲 | WebGL 置换效果；轻量替代：hover 时 `scale(1.05)` + `filter` 变化 + clip-path 裁切动画 |
| 横向滚动章节 | 垂直滚动驱动一个横向长画布平移（ScrollTrigger pin + x 位移），适合时间线/作品集 |
| 滚动速度感 | 滚动越快元素越倾斜/拉伸（监听 velocity），停止后弹回 |

## 第二部分：模式速查表

### 开场类（Hero 专用）

| 模式 | 效果 | 成本 | 惊艳度 |
|------|------|:--:|:--:|
| 巨字逐字浮起 | 标题按字翻入，节奏感极强 | 低 | ★★★★ |
| 模糊聚焦定场 | 全屏标题从 blur(20px) 渐清晰 | 极低 | ★★★ |
| 流动渐变背景 | 极光式色斑缓慢流动 | 低 | ★★★★ |
| 浮动卡片拼贴 | 多张倾斜卡片漂浮 + 鼠标视差 | 中 | ★★★★ |
| canvas 粒子场 | 粒子随鼠标聚散/连线 | 中 | ★★★ |
| 开幕式 loader | 进站时遮罩拉开/计数器 0→100 后揭幕 | 中 | ★★★★★ |

### 滚动叙事类（中段 sections）

| 模式 | 效果 | 成本 | 惊艳度 |
|------|------|:--:|:--:|
| scroll reveal | 元素进入视口时 fade + 上移，全页基础款 | 极低 | ★★ |
| stagger 编队进场 | 卡片组依次错峰进场（间隔 0.08~0.15s） | 低 | ★★★ |
| sticky 定格叙事 | 一屏固定，屏内内容随滚动切换 | 中 | ★★★★★ |
| 横向滚动章节 | 垂直滚动驱动横向平移 | 中 | ★★★★★ |
| 视差分层 | 前后景不同速度滚动产生景深 | 低 | ★★★ |
| 数字滚动累加 | 统计数字从 0 跳到目标值 | 低 | ★★★ |
| SVG 路径绘制 | 线条/插画随滚动逐渐画出 | 中 | ★★★★ |
| 卡片堆叠 | 滚动时卡片一张张叠到前一张上（sticky + scale） | 中 | ★★★★ |
| 文字逐词高亮 | 大段宣言文字随滚动逐词从灰变亮 | 低 | ★★★★ |
| 图片裁切揭示 | 图片以 clip-path 从条带/圆形展开 | 低 | ★★★ |

### 微交互类（hover/click）

| 模式 | 效果 | 成本 |
|------|------|:--:|
| 磁性按钮 | 鼠标靠近时按钮被"吸"向光标，离开弹回 | 低 |
| 3D 按压按钮 | 厚底按钮按下去（Duolingo 式） | 极低 |
| 卡片 3D 倾斜 | hover 时卡片随鼠标位置 rotateX/Y，配高光 | 低 |
| 文字滚动替换 | hover 时按钮文字向上滚出、副本滚入 | 低 |
| 链接下划线生长 | 下划线从左到右画出 | 极低 |
| 自定义光标 | 圆环延迟跟随，hover 时变形 | 中 |
| marquee 无限滚动条 | logo 墙/口号横向无限循环，hover 减速 | 低 |

### 氛围质感类（全页贯穿，挑一种）

| 模式 | 效果 |
|------|------|
| 噪点 overlay | 全页覆盖 3~5% 透明度噪点（SVG feTurbulence），消除"数码塑料感" |
| 辉光体系 | 暗色底 + 品牌色 box-shadow 辉光（Linear 式） |
| 玻璃拟态 | backdrop-filter 毛玻璃卡片 + 细高光边 |
| 纸张/印刷感 | 米白底 + 衬线字 + 细分割线 + 噪点，编辑部气质 |
| 点阵/网格背景 | 工程蓝图感的细网格或点阵 |

## 第三部分：组合搭配建议

按基调原型给出的成套搭配（可直接采用，也可替换单项）：

**科技旗舰套**（Apple/Linear 系）：开幕 loader 或模糊聚焦 + sticky 定格叙事（签名）+ 辉光质感 + stagger 进场 + 磁性按钮。缓动 `power2.inOut`~`power3.out`，时长偏长（0.8~1.4s）。

**活泼游戏套**（Duolingo 系）：巨字逐字浮起（弹性缓动）+ 角色浮动 + 3D 按压按钮 + 庆祝粒子（签名）+ 波浪分隔 + 数字滚动。缓动 `back.out(1.7)`，时长偏短（0.4~0.7s）。

**创意工具套**（Canva/Figma 系）：浮动卡片拼贴 + 鼠标视差（签名）+ 流动渐变背景 + marquee + 卡片 3D 倾斜。缓动 `power2.out`，跟随用 lerp。

**工程信赖套**（Stripe 系）：流动渐变 Hero（签名）+ 代码窗口打字 + SVG 图表绘制 + 细网格质感 + 链接下划线。动画少而准。

**先锋作品集套**（Awwwards 系）：自定义光标 + 巨字逐字 + 横向滚动章节（签名）+ 图片裁切揭示 + 噪点质感。配 Lenis 平滑滚动是灵魂。

**温暖品牌套**（消费品/餐饮/生活方式）：模糊聚焦定场 + SVG 路径绘制（签名，如蒸汽/手绘线条）+ 文字逐词高亮 + 视差 + 纸张质感。衬线字体，节奏舒缓。
